# 押し目の EV を「個別 RS」と「業種 RS の測り方」で分ける（2026-10-16 週次レビュー）

問い（JAL の手仕舞いから）:
1. 個別の rs60（対 TOPIX、60 日）が負の銘柄は、押し目として EV が低いのか。
2. 業種 RS は rs20_med（PLAYBOOK の現行）と rs60_med のどちらで上位 1/3 を選ぶと EV が高いか。

データ: 東証内国株、2023-10〜2026-10-15（3 年）。pullback シグナル・4 フラグ OK、翌日寄り建て、決済 12/-6/15、往復 0.2%。n=3,345（直近 400 日 n=1,388）。表の全量は `2026-10-16_rs_filter_tables.md`、トレード一覧は `_rs_filter.csv`。スクリプト `2026-10-16_rs_filter.py`。

## 結論
1. **「個別 rs60 が負なら買わない」は誤り。** rs60 が -10〜0% の帯は EV +1.09%（勝率 55%、PF 1.59）で、0〜10% の +0.48% より良い。直近 400 日でも +1.25% vs +0.68%。悪いのは **-10% 未満**だけ（全期間 +0.12%、直近 -0.49%、PF 0.8）。「業種は強いが個別は少し出遅れ」が押し目の本命で、JAL（rs60 -2%）の建玉はこの基準では正しかった。負けの原因は個別 RS ではなく、空運の業種 RS が建玉後に崩れたこと。
2. **業種 RS は rs60_med で測る方が分離が良い。** 上位 1/3 vs 下位 1/3 の EV は rs60 で +1.12% vs +0.26%（直近 400 日 +2.10% vs +0.09%）、rs20 では +0.94% vs +0.41%（直近 +1.91% vs +0.48%）。rs20 と rs60 を組み合わせると「rs20 上位 × rs60 下位」が最悪（-0.22%、n=91）、「両方上位」が最良（+1.30%、n=684）。20 日の RS だけ高い業種は短期の資金流入で、押し目を買う頃には抜けている。
3. 個別 rs20 が +5〜15% の帯は EV -0.16%（n=394）。20 日で走った銘柄の最初の押しは買われない。今週は規則にしないが、来週以降の候補。
4. 地合い下（regime 0）では rs60 > 0 の銘柄が EV +0.14% まで落ちる一方、rs60 ≤ 0 は +0.65% を保つ。地合い下で買うなら出遅れ側。

## PLAYBOOK への反映（今週のルール変更は 1 つ）
- 銘柄選定 4.: 業種 RS の順位を **rs60_med** で見る（上位 1/3 を優先、下位 1/3 を見送る）。rs20_med が上位でも rs60_med が下位なら見送り。
- 個別 rs60 < -10% は候補から外す（選定 3. の順位付けに追記。これは新しい制約ではなく、同じ検証から出た足切り）。
- 保有の「業種 RS が崩れた」判定も rs60_med が下位 1/3 に落ちたときとする。

## 注意
- 業種 RS の三分位は日付ごとに 33 業種を順位付けしたもの（n≥5 の業種のみ）。sector_rs.csv の rs20_med / rs60_med と同じ定義。
- 期間は上昇相場寄り。地合い下の n は少ない（780）。
